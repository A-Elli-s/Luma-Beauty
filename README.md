# Luma Beauty

Luma Beauty is a lightweight affiliate-focused beauty discovery website built around frequently purchased makeup categories such as lipstick, eyeshadow, face products, and beauty tools.

## Current version

- Responsive homepage
- Category navigation
- Filterable product cards
- Mobile navigation
- Affiliate disclosure
- Placeholder product content ready to be replaced with approved affiliate products and tracked links
- No framework or database required

## Files

- `index.html` — site structure and content
- `styles.css` — responsive visual design
- `script.js` — navigation and product filtering

## Next steps

1. Choose and join affiliate programs.
2. Replace placeholder products with approved real products and affiliate links.
3. Add product imagery that we have permission to use.
4. Deploy the site publicly.
5. Add analytics and a repeatable product-update workflow.

> Important: Affiliate program terms vary. Product images, pricing, claims, trademarks, and affiliate links should be used according to each program's rules.
